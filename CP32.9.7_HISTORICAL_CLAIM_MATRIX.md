## 1. Evidence Taxonomy

Every claim in this matrix is classified strictly under one of the 6 evidence categories:

* **`CURRENT_CODE`:** Demonstrates actual code present in the active worktree. Does not prove historical state prior to commit history.
* **`DOCUMENTATION`:** Demonstrates what is stated in specification or baseline markdown files (`CP31_PRE_IMPLEMENTATION_BASELINE.md`, `PHASE_30_ICT_MODEL_V1_SPECIFICATION.md`).
* **`GIT_HISTORY`:** Demonstrates facts traceable to explicit git commit objects (`d5fdae9`, `590a068`).
* **`CRYPTOGRAPHIC`:** Demonstrates exact byte-level identity via SHA-256 hash digests of identical file scope.
* **`TEST`:** Demonstrates that execution assertions passed under current runtime environment.
* **`INFERENCE`:** Logical deduction not directly backed by primary code/git/hash evidence. *Never classified as VERIFIED.*
