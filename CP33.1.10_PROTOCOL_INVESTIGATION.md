## 5. Determination of the 31-Candle Limit Cause

* **Cause Analysis**:
  The 31 candles received represent the default initial push frame size delivered by TradeSea's backend WebSocket server upon session initialization for the active NQ 5m viewport window. Because TradeSea's client interface does not trigger secondary REST or WebSocket pagination requests when dragging backward, the initial 31 bars are the sole historical data pushed over the live stream.
* **Limit Classification**: `LIMIT_CAUSE = INITIAL_WEBSOCKET_PUSH_FRAME_LIMIT`.
