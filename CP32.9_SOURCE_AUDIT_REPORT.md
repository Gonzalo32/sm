## 3. CLASIFICACIÓN DE TRES NIVELES POR CONCEPTO Y PARÁMETROS

Se separaron obligatoriamente los tres niveles de conocimiento para prevenir la atribución ilegítima de decisiones de código como "teoría oficial de ICT":

### 3.1 BOS y MSS (`CONCEPT-04` / `CONCEPT-05`)
- **Nivel A (Concepto Documentado)**: Ruptura de estructura para continuidad (BOS) o reversión (MSS).
- **Nivel B (Interpretación)**: Ruptura por Cierre de Cuerpo (`Body Close`) vs Penetración por Mecha (`Wick Penetration`).
- **Nivel C (Regla Operativa del Indicador)**: La decisión de exigir `Close > Swing High` (BOS/MSS Alcista) y `Close < Swing Low` (BOS/MSS Bajista) se clasifica explícitamente como **`PROJECT_OPERATIONAL`**. No se presenta como una ley física universal de ICT, sino como la regla determinista V1 del proyecto respaldada por la cita de ICT: *"Bodies tell the story, wicks hold the damage"*.

### 3.2 Order Block (`CONCEPT-14`)
- **Nivel A (Concepto Documentado)**: Vela previa a un impulso institucional que genera desbalance y ruptura estructural.
- **Nivel B (Interpretación)**: Variante A (última vela de color contrario) vs Variante B (vela de origen del FVG) vs Rango solo cuerpo vs Rango completo con mechas.
- **Nivel C (Regla Operativa del Indicador)**: La selección de la **Variante B completa ($High$-$Low$)** que origina la expansión FVG se clasifica como **`PROJECT_OPERATIONAL`**.

### 3.3 Fair Value Gap (`CONCEPT-13`)
- **Nivel A (Concepto Documentado)**: Patrón de 3 velas con espacio desocupado entre $High(V_1)$ y $Low(V_3)$.
- **Nivel B (Interpretación)**: Gap geométrico puro ($> 0$ pips) vs Gap filtrado por tamaño de volatilidad.
- **Nivel C (Regla Operativa del Indicador)**: El parámetro de tamaño mínimo `fvgMinSizePoints` (default: 0.25) y los estados del ciclo de vida (`ACTIVE`, `PARTIALLY_MITIGATED`, `FULLY_MITIGATED`, `INVALIDATED`) se clasifican como **`PROJECT_OPERATIONAL`**.

### 3.4 Desplazamiento (`CONCEPT-12`)
- **Nivel A (Concepto Documentado)**: Expansión de rango con cuerpos largos y mechas cortas.
- **Nivel B (Interpretación)**: Percepción cualitativa de energía ICT vs Umbrales algorítmicos.
- **Nivel C (Regla Operativa del Indicador)**: Los umbrales de `bodyRatio >= 0.65` y `rangeMultiplier >= 1.50` son parámetros exclusivos de software clasificados como **`PROJECT_OPERATIONAL`**.

### 3.5 Modelos A, B y C (`CONCEPT-19`, `CONCEPT-20`, `CONCEPT-21`)
- **Nivel A (Concepto Documentado)**: Secuencias temáticas documentadas en ICT (Silver Bullet, AMD/Judas, Retest de Estructura).
- **Nivel B (Interpretación)**: Ensamblaje de múltiples componentes (Sweep + MSS + FVG/OB).
- **Nivel C (Regla Operativa del Indicador)**: Las estructuras discretas de setups Model A, Model B y Model C se clasifican formalmente como **`PROJECT_MODEL_V1`** (`PROJECT_OPERATIONAL`).
