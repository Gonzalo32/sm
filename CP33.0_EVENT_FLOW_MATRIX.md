## 2. Event Sorting & Resolution Rule

At Step 10 of `ICTEngine.process()`, all generated events are deterministically sorted by:
```typescript
allEvents.sort(
  (a, b) =>
    a.confirmationTimestamp - b.confirmationTimestamp ||
    a.eventTimestamp - b.eventTimestamp ||
    a.candleIndex - b.candleIndex
);
```
This guarantees 100% deterministic sequence ordering across multiple execution runs on identical datasets.
