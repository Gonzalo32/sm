## 1. Disagreement Taxonomy Categories

Every potential discrepancy identified during real market replay is classified strictly into one of the 7 taxonomy categories:

* **D1 — Detection Error:** Engine detects something that violates its own explicit code rule.
* **D2 — Timing Error:** Event exists but timestamp or confirmation timestamp is misordered.
* **D3 — Integration Error:** Individual engines function, but multi-engine event flow fails.
* **D4 — Conceptual Ambiguity:** Rule allows more than one reasonable domain interpretation (e.g., FVG 50% vs Touch mitigation).
* **D5 — Dataset Ambiguity:** Real market data contains gaps or unresolvable price jumps.
* **D6 — Documentation Issue:** Code behavior differs from text documentation.
* **D7 — Unknown:** Insufficient evidence to classify.
