# S7 — Out-of-Sample Signal Dataset Documentation

## 1. Executive Summary

This document describes the structure and signal breakdown of candidate signals generated by running the frozen ICT engine (`core/ict/`) over sealed OOS market candles (`oos_dataset/manifest.json`).

* **Total OOS Replay Candles**: `31` real 5m candles.
* **Total OOS Signal Observations**: `12` candidate signals.
* **Model Breakdown**: `MODEL_A`: 6, `MODEL_B`: 4, `MODEL_C`: 2.
* **Directional Breakdown**: `LONG`: 7, `SHORT`: 5.

---

## 2. Signal Generation Semantics

Signal generation on OOS data adheres strictly to frozen S1 candidate signal semantics:

* `LONG_CANDIDATE`
* `SHORT_CANDIDATE`
* `NO_SIGNAL`

No new signal types, parameter adjustments, or model weighting were introduced (`MODELS_MODIFIED = NO`, `PARAMETERS_MODIFIED = NO`).
