# CP40 — VISUAL OBJECT LINEAGE REPORT

## 1. VISUAL OBJECT LINEAGE ATTRIBUTES
Every visual overlay object generated by `VisualAdapter` includes full provenance metadata:
* `id`: Formatted as `VIS-<SourceID>` (e.g. `VIS-ctx_NQ_1m_100000` or `VIS-SWG-HIGH-10`).
* `symbol`: Matches source candle symbol.
* `timeframe`: Matches source candle timeframe.
* `timestamp`: Event timestamp or candle timestamp.
* `price`: Exact price coordinate.
* `label`: Descriptive text string (e.g. `ICT CONTEXT: CONTEXT_CONFIRMED`).
* `zIndex`: Visual hierarchy level (1 to 50).

## 2. DERIVED PRESENTATION GUARANTEE
`VisualObject` is 100% derived from logical state. Mutating, zooming, or scrolling visual objects NEVER mutates underlying `CandleStore` memory or `ICTEvents`. Zero untraceable visual shapes exist.
