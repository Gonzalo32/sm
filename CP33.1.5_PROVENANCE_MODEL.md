## 1. Runtime Provenance Metadata Contract

Every active market data adapter session maintains an immutable in-memory provenance metadata payload accessible via `MarketDataAdapter.getProvenanceMetadata()`:

```typescript
export interface RuntimeProvenanceMetadataPayload {
  source: string;                       // Data feed provider identifier
  instrument: 'MNQ' | 'NQ';             // Target instrument symbol
  timeframe: '1m' | '5m' | '15m';       // Target timeframe label
  timezone: string;                     // Session timezone (e.g. UTC / EST)
  requestedLookbackDays: number;        // Lookback target (60 days)
  actualAvailableLookbackDays: number;  // Measured availability in days
  firstTimestamp: number | null;        // First candle epoch ms in store
  lastTimestamp: number | null;         // Last candle epoch ms in store
  candleCount: number;                  // Total active candles in memory
  connectionStatus: string;             // DISCONNECTED | CONNECTED | RECONNECTING | ERROR
  syntheticBlocked: boolean;            // Synthetic source protection status
}
```

## 2. Synthetic Runtime Protection Policy

```text
SYNTHETIC_RUNTIME_BLOCKED = YES
```

1. **Synthetic Source Detector:** `MarketDataAdapter` inspects `sourceContract.isSynthetic` and source name string flags (`CP21`, `synthetic`, `mock`, `fixture`).
2. **Real Runtime Mode (`requireRealRuntime = true`)**:
   - If a synthetic source is passed into `MarketDataAdapter` in real runtime mode, the ingestion is immediately halted.
   - Return Status: `REJECTED_FOR_REAL_RUNTIME`.
   - Result: Synthetic dataset `CP21DatasetGenerator` can **never** act as a silent fallback for real market runtime execution.
3. **Missing Source Handling:** If no real market data source is available, the adapter returns `REAL_DATA_UNAVAILABLE` rather than generating artificial candles.
